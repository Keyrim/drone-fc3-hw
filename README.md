# drone-fc3-hw

Third-generation flight controller: STM32F722 all-in-one board, 36x36 mm, KiCad,
JLCPCB assembly. Project symbols and footprints in `lib/`, board in `mark4-fc/`,
fab package in `mark4-fc/exports/`.

Design docs in `docs/` (spec, design, pinmap, components, status, sensor board).
Firmware: [drone-throw](https://github.com/Keyrim/drone-throw).

History split out of drone-throw (formerly drone-mark4) on 2026-10-20.
